# القرآن الكريم - تطبيق إسلامي شامل PWA

## المميزات الرئيسية

### 📖 القرآن الكريم
- قراءة القرآن الكريم كاملاً (114 سورة)
- نظام التنقل بين الصفحات (10 آيات في كل صفحة)
- الانتقال التلقائي إلى السورة التالية
- نظام الإشارات المرجعية (حفظ آخر موضع قراءة)
- شاشة مخصصة لاختيار السور مع البحث

### 🤲 الأذكار
- 7 فئات شاملة:
  - أذكار الصباح (10 أذكار)
  - أذكار المساء (9 أذكار)
  - أذكار النوم (8 أذكار)
  - أذكار الاستيقاظ (3 أذكار)
  - أذكار الصلاة (10 أذكار)
  - أذكار عامة (8 أذكار)
  - سور قرآنية (5 سور)
- مع المراجع والشرح لكل ذكر

### 📿 المسبحة الإلكترونية
- عداد رقمي مع حلقة تقدم بصرية
- أهداف محددة مسبقاً: 33، 99، 100، 1000
- إمكانية تعيين هدف مخصص
- نظام الصوت القابل للتبديل
- حفظ السجل التاريخي (آخر 10 مرات)
- دعم لوحة المفاتيح (مسافة للعد)

### ⚙️ الإعدادات المتقدمة

#### المظهر
- **الوضع الليلي**: تبديل بين الوضع الفاتح والداكن
- **تغيير اللون الأساسي**: 6 ألوان للاختيار من بينها
  - أخضر (افتراضي)
  - أزرق
  - بنفسجي
  - برتقالي
  - بني
  - رمادي مزرق

#### الخط
- **تكبير/تصغير الخط**: 4 أحجام (صغير، متوسط، كبير، كبير جداً)
- معاينة مباشرة للتغييرات
- خط Amiri الاحترافي للنصوص العربية

#### التنبيهات
- تفعيل/إلغاء تفعيل التنبيهات
- إضافة تنبيهات متعددة
- اختيار أيام محددة لكل تنبيه
- اختيار الوقت المحدد
- إشعارات تلقائية في الأوقات المحددة

### 📱 مميزات PWA
- تثبيت التطبيق على الشاشة الرئيسية
- العمل دون اتصال بالإنترنت (بعد التحميل الأول)
- تجربة تطبيق أصلي كامل
- سرعة فائقة في التحميل
- حجم خفيف

## التقنيات المستخدمة
- HTML5
- CSS3 مع CSS Variables للثيمات
- JavaScript Vanilla (بدون مكتبات خارجية)
- Service Worker للعمل بدون إنترنت
- Web Notifications API
- LocalStorage للتخزين المحلي
- Quran API: api.alquran.cloud
- خط Amiri من Google Fonts

## التثبيت والاستخدام

### على الهاتف المحمول:
1. افتح الموقع في المتصفح (Chrome, Safari, Edge)
2. اضغط على زر "إضافة إلى الشاشة الرئيسية"
3. أو من الإعدادات → تثبيت التطبيق

### على الكمبيوتر:
1. افتح الموقع في Chrome, Edge, أو Brave
2. اضغط على أيقونة التثبيت في شريط العنوان
3. أو من الإعدادات → تثبيت التطبيق

### تحميل صفحات المصحف محليا (اختياري)
يمكن تنزيل صفحات المصحف (1-604) داخل المشروع في `assets/mushaf-pages`:

```bash
npm run download:mushaf
```

إعادة تنزيل كل الصفحات (مع استبدال الملفات الموجودة):

```bash
npm run download:mushaf -- --force
```

القراءة في وضع المصحف تستخدم الصور المحلية أولا، وإذا لم تجد الصفحة محليا تستخدم المصدر الاحتياطي عبر الإنترنت.

## بناء كتطبيق أصلي (iOS / Android) عبر Capacitor

المشروع مغلف الآن بـ [Capacitor](https://capacitorjs.com) بحيث يمكن إصدار نفس
الـ PWA كتطبيق iOS و Android أصلي بدون إعادة كتابة الكود.

### المتطلبات
- Node 18+ و npm (مثبتة بالفعل)
- لـ iOS: Xcode 15+ على macOS
- لـ Android: Android Studio و Java 17+

### الأوامر

```bash
# نسخ ملفات الويب إلى www/ (مصدر التطبيق الأصلي)
npm run build:www

# مزامنة www مع المشاريع الأصلية بعد أي تعديل
npm run cap:sync

# فتح المشروع في Xcode
npm run cap:ios

# فتح المشروع في Android Studio
npm run cap:android

# تشغيل مباشر على جهاز/محاكي متصل
npm run cap:run:ios
npm run cap:run:android
```

### دورة العمل
1. عدل ملفات HTML/CSS/JS كالمعتاد
2. شغل `npm run cap:sync` لنقل التغييرات إلى المشاريع الأصلية
3. أعد البناء من Xcode / Android Studio

### إضافات Capacitor المثبتة
- `@capacitor/local-notifications` — إشعارات تعمل حتى مع إغلاق التطبيق (لمواقيت الصلاة والأذكار)
- `@capacitor/haptics` — اهتزاز عند الضغط على المسبحة
- `@capacitor/preferences` — تخزين أصلي بدلاً من localStorage عند الحاجة
- `@capacitor/splash-screen` و `@capacitor/status-bar` و `@capacitor/app`

### معرف التطبيق
`app.quran.fady` — يمكن تغييره من `capacitor.config.json` (يجب حذف مجلدي `ios/` و `android/` وإعادة `npx cap add` بعد التغيير).

### الويدجتس (Home Screen Widgets)
- **iOS (WidgetKit)**: ودجتان جاهزتان — "الصلاة القادمة" و "آية اليوم".
  مصدر السويفت موجود في `ios/QuranWidget/`. يجب إنشاء target الـ Widget
  Extension يدوياً في Xcode مرة واحدة، التفاصيل في
  [docs/native-setup.md](docs/native-setup.md).
- **Android (AppWidget)**: نفس الودجتين — مسجلتان تلقائياً في
  `AndroidManifest.xml` ولا تحتاجان أي خطوات يدوية.

البيانات تتدفق إلى الويدجتس عبر إضافة `WidgetBridge` المخصصة:
- `prayer-times.html` تدفع وقت الصلاة القادمة بعد كل تحديث.
- الصفحة الرئيسية تدفع آية اليوم عند تحميل `loadDailyVerse()`.

### إنشاء الأيقونات والـ Splash
```bash
npx capacitor-assets generate
```
يقرأ من `assets/icon-only.svg`, `assets/icon-foreground.svg`,
`assets/icon-background.svg`, و `assets/splash.svg` ويولّد جميع الأحجام
لـ iOS و Android و PWA.
