## 🚀 كيفية الاستخدام

### التشغيل المحلي:
```bash
# طريقة 1: Python
python server.py

# طريقة 2: Batch (Windows)
start-server.bat

# طريقة 3: Node.js
npx http-server -p 8000
```

### التثبيت كـ PWA:
1. افتح التطبيق في المتصفح
2. انقر على أيقونة التثبيت في شريط العنوان
3. أو من الإعدادات → تثبيت التطبيق

### تفعيل الإشعارات:
1. إعدادات → التنبيهات
2. فعّل "تفعيل التنبيهات"
3. اسمح بالإشعارات في المتصفح
4. أضف تنبيهات جديدة

## 🎨 تخصيص الثيم

### البرمجة:
```javascript
// تغيير اللون الأساسي
localStorage.setItem('primaryColor', '#2196F3');

// تفعيل الوضع الداكن
document.documentElement.setAttribute('data-theme', 'dark');
localStorage.setItem('darkMode', 'true');

// تغيير حجم الخط
const fontSizes = [14, 16, 18, 20];
const baseSize = fontSizes[2]; // كبير
document.documentElement.style.setProperty('--font-size-base', baseSize + 'px');
```

### CSS Variables المتاحة:
```css
--primary-color: اللون الأساسي
--primary-light: اللون الفاتح
--bg-color: لون الخلفية
--text-color: لون النص
--card-bg: لون الكروت
--border-color: لون الحدود
--shadow: الظل
--font-size-base: حجم الخط الأساسي
--font-size-ayah: حجم خط الآيات
--font-size-header: حجم خط العناوين
```
