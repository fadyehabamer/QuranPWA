# القرآن الكريم - تطبيق إسلامي شامل PWA

[![CI](https://github.com/fadyehabamer/QuranPWA/actions/workflows/ci.yml/badge.svg)](https://github.com/fadyehabamer/QuranPWA/actions/workflows/ci.yml)

## المميزات الرئيسية

### 📖 القرآن الكريم
- قراءة القرآن الكريم كاملاً (114 سورة)
- نظام التنقل بين الصفحات (10 آيات في كل صفحة)
- الانتقال التلقائي إلى السورة التالية
- نظام الإشارات المرجعية (حفظ آخر موضع قراءة)
- شاشة مخصصة لاختيار السور مع البحث

### 🤲 الأذكار
- 7 فئات شاملة:
  - أذكار الصباح (10 أذكار)
  - أذكار المساء (9 أذكار)
  - أذكار النوم (8 أذكار)
  - أذكار الاستيقاظ (3 أذكار)
  - أذكار الصلاة (10 أذكار)
  - أذكار عامة (8 أذكار)
  - سور قرآنية (5 سور)
- مع المراجع والشرح لكل ذكر

### 📿 المسبحة الإلكترونية
- عداد رقمي مع حلقة تقدم بصرية
- أهداف محددة مسبقاً: 33، 99، 100، 1000
- إمكانية تعيين هدف مخصص
- نظام الصوت القابل للتبديل
- حفظ السجل التاريخي (آخر 10 مرات)
- دعم لوحة المفاتيح (مسافة للعد)

### ⚙️ الإعدادات المتقدمة

#### المظهر
- **الوضع الليلي**: تبديل بين الوضع الفاتح والداكن
- **تغيير اللون الأساسي**: 6 ألوان للاختيار من بينها
  - أخضر (افتراضي)
  - أزرق
  - بنفسجي
  - برتقالي
  - بني
  - رمادي مزرق

#### الخط
- **تكبير/تصغير الخط**: 4 أحجام (صغير، متوسط، كبير، كبير جداً)
- معاينة مباشرة للتغييرات
- خط Amiri الاحترافي للنصوص العربية

#### التنبيهات
- تفعيل/إلغاء تفعيل التنبيهات
- إضافة تنبيهات متعددة
- اختيار أيام محددة لكل تنبيه
- اختيار الوقت المحدد
- إشعارات تلقائية في الأوقات المحددة

### 📱 مميزات PWA
- تثبيت التطبيق على الشاشة الرئيسية
- العمل دون اتصال بالإنترنت (بعد التحميل الأول)
- تجربة تطبيق أصلي كامل
- سرعة فائقة في التحميل
- حجم خفيف

## التقنيات المستخدمة
- HTML5
- CSS3 مع CSS Variables للثيمات
- JavaScript Vanilla (بدون مكتبات خارجية)
- Service Worker للعمل بدون إنترنت
- Web Notifications API
- LocalStorage للتخزين المحلي
- Quran API: api.alquran.cloud
- خط Amiri من Google Fonts

## التثبيت والاستخدام

### على الهاتف المحمول:
1. افتح الموقع في المتصفح (Chrome, Safari, Edge)
2. اضغط على زر "إضافة إلى الشاشة الرئيسية"
3. أو من الإعدادات → تثبيت التطبيق

### على الكمبيوتر:
1. افتح الموقع في Chrome, Edge, أو Brave
2. اضغط على أيقونة التثبيت في شريط العنوان
3. أو من الإعدادات → تثبيت التطبيق

### تحميل صفحات المصحف محليا (اختياري)
يمكن تنزيل صفحات المصحف (1-604) داخل المشروع في `assets/mushaf-pages`:

```bash
npm run download:mushaf
```

إعادة تنزيل كل الصفحات (مع استبدال الملفات الموجودة):

```bash
npm run download:mushaf -- --force
```

القراءة في وضع المصحف تستخدم الصور المحلية أولا، وإذا لم تجد الصفحة محليا تستخدم المصدر الاحتياطي عبر الإنترنت.
